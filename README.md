# Atyrau University Monitor

Автоматизированный мониторинг общедоступных источников Атырауского университета имени Х. Досмухамедова.

## Что проверяется

- Рекурсивный обход доступных HTML-страниц официального сайта на русском и казахском языках.
- robots.txt, XML-карты сайта и внутренние ссылки.
- Документы PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX; извлечение доступного текстового содержимого.
- Публичные страницы Instagram и Facebook, если они доступны без авторизации и CAPTCHA.
- Упоминания в СМИ через Google News RSS на русском, казахском и английском языках.

## Расписание

Понедельник–суббота, два запуска в день:
- 06:00 Asia/Almaty (UTC+5)
- 16:00 Asia/Almaty (UTC+5)

GitHub Actions может задерживать старт. Каждый запуск продолжает незавершённую очередь, если сохранённое состояние доступно.

## Состояние и конфиденциальность

Контрольные точки и снимки сохраняются в GitHub Actions cache, а не в публичных файлах репозитория. Кэш может быть удалён платформой; при его отсутствии мониторинг начнёт формировать новый исходный снимок. Отчёты запуска доступны в GitHub Actions artifacts.

## Email

Для отправки отчёта настройте в Settings → Secrets and variables → Actions следующие секреты:
- SMTP_HOST
- SMTP_PORT
- SMTP_USERNAME
- SMTP_PASSWORD
- SMTP_FROM
- REPORT_EMAIL_TO

Не размещайте пароли, токены и другие секреты в исходном коде или открытых файлах.

## Ограничения

Мониторинг не обходит авторизацию, CAPTCHA или технические ограничения источников. RSS и доступность социальных сетей не гарантируют исчерпывающий охват всего интернета. Неполный обход не трактуется как подтверждённое отсутствие изменений.
